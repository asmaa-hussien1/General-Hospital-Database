# General Hospital Database
## Project Description
This project represents a database system for a General Hospital.
The system manages:
- Wards
- Patients
- Consultants
- Nurses
- Drugs
- Drug Administration
## Database Components
### ERD
The Entity Relationship Diagram represents the entities and relationships.
### Relational Schema
The schema shows the tables, primary keys, and foreign keys.
### SQL Database
The SQL script creates the database, tables, constraints, and relationships.
